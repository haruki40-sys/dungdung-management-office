# 오늘도 관리사무소 v1.5.0

3막 「벽 안의 물소리」: 16~20일차, 관리 계획, 전체 회상, 4막 예고를 플레이할 수 있습니다.

첫 화면에서 3막을 바로 시작하거나 2막 결과를 설정합니다. 같은 주소에 저장된 2막 완료 진행 또는 2막 완료 JSON을 불러올 수 있습니다. 기본 시작 조건은 이월 80만 원, A·B 1단계, C·D·E 0단계, 전용 쉼터 용도입니다.

점검 기사는 사용자 제공 인물 그림으로 다른 인물과 동일한 대화 방식에 등장합니다. 물자국, 옛 사진, 공용실 안내문, 스캔 화면, 도면 컷인을 포함합니다. 공용실은 안전 확인 전 사용을 제한합니다. 16일차에는 위치를 비교하고 18일차에 같은 배수 문제임을 확인합니다.

관리 계획은 계약·준비 단계입니다. 시설 단계는 21일차 완료 확인 전 오르지 않습니다. 21일차 이후 플레이는 이번 버전에 포함하지 않습니다.

기존 2막 저장 키 `office_v10_apply`를 보존하고 3막 진행은 별도 키 `office_act3_local_review_v1`로 저장합니다. 브라우저와 주소가 달라지면 진행 저장도 별도로 취급됩니다.
