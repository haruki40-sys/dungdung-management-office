# 오늘도 관리사무소 v1.4.1

아파트 관리사무소를 배경으로 주민의 사정을 듣고 선택과 관리계획을 남기는 브라우저 게임입니다. 이번 공개본은 2막 8~15일차부터 시작합니다.

## 실행

GitHub Pages 또는 일반 정적 웹 서버에서 `index.html`을 엽니다. 외부 CDN 없이 모든 파일을 상대경로로 불러옵니다.

## 플레이

- 2막 8·9·12·13·15일차에는 선택지가 있고, 10·11·14일차는 이야기로 진행됩니다.
- 선택에 따른 사건비와 관리계획이 공간 단계에 반영됩니다.
- 2막 관리 결과와 전체 회상 뒤 3막 예고가 나옵니다. 3막 본편은 아직 없습니다.
- 이전 1막 저장이 있으면 관리계획 결과와 선택 기록을 승계합니다. 저장이 없으면 복도 안전과 주민 쉼터가 1단계인 기본 상태로 시작합니다.

## 파일

- `index.html` — 게임 진입점
- `css/` — 화면 스타일
- `js/game.js` — 1막 데이터와 공통 진행·저장 로직
- `js/act2-data.js` — 2막 사건 데이터
- `assets/` — 배경, 캐릭터, 컷인, 소품, 배경음악
- `saves/save-sample.json` — 2막 시작 상태 예시

## 저장과 음악

진행 저장 키 `office_v10_apply`와 저장 구조 `schema: 2`를 유지합니다. 2막 상태는 기존 저장의 `storyState`에 시설 단계와 예산 등을 함께 기록합니다. 구형 v1.2.1 저장은 원본을 `office_v10_apply_legacy_v1_2_1`에 백업합니다.

배경음악 `Forget Me Not` (looped)은 Kistol의 CC0 곡입니다. [출처](https://opengameart.org/content/forget-me-not).
